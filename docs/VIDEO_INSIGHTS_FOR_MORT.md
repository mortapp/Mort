Transcript access: English auto-generated captions were available. This document contains original analysis only, not a transcript dump.

## Video Topic

The video explains six UX psychology principles that improve conversion and retention when used responsibly:

- Smart defaults
- Goal-gradient progress
- Reciprocity
- User investment / ownership
- Loss aversion and status-quo bias
- Contrast effect / anchoring

## Key Product Ideas

- Reduce blank-page friction by recommending safe defaults.
- Make users feel they have already started instead of showing zero progress.
- Give real value before asking for more commitment.
- Let users build something personal early.
- Show the cost of inaction carefully, without threats or shame.
- Present prices in context instead of isolated numbers.

## Onboarding Ideas

- Count account creation as progress instead of starting onboarding at 0%.
- Show a short progress indicator on each step.
- Give role-specific reasons for each required field.
- Use safe defaults for locality, availability, and payment preference.
- Let teens, adults, and guardians understand their paths before filling forms.
- Keep required safety/legal steps non-skippable.

## Paywall Ideas

- Give a useful free experience before showing optional perks.
- Show exactly what stays free before showing paid products.
- Use RevenueCat/App Store price strings as truth.
- Present subscriptions, lifetime, one-time, and consumable products in context.
- Keep "Keep using free" visible and emotionally neutral.
- Avoid fake urgency, fake discounts, shame copy, or "pay to be safe" framing.

## Pricing Ideas

- Use low-friction, inexpensive optional perks.
- Compare paid perks to convenience and personalization, not safety.
- Let lifetime and one-time products reduce subscription pressure.
- Show package prices only from RevenueCat/App Store/Test Store data.

## Retention Ideas

- Profile completion can become a safe progress loop.
- Saved jobs, folders, goals, weekly summaries, and trust reminders can create return loops.
- Guardian weekly digest can help adults return without locking basic supervision.
- Job posters can return for reusable safe-job templates and applicant organization.

## UI/UX Ideas

- Avoid blank forms where MORT can recommend a safe default.
- Use short cards, badges, progress bars, and concise helper copy.
- Empty states should suggest the next safe action.
- CTAs should say what happens next, not generic "continue" everywhere.
- Native-only features should say native app required in web preview.

## Trust/Safety Ideas

- Safety tools must be visible before monetization.
- Report, block, Safety Ping, message scanning, proof basics, and Guardian Mode basics must remain free.
- Exact location warnings should appear near locality and messaging surfaces.
- Verification should be explained as trust and moderation, not as a paid shortcut.
- Boosts must never bypass safety review.

## App Store/TestFlight/Release Ideas

- Screenshots should show free safety tools, teen-safe job feed, Guardian Mode, adult verification, and optional perks.
- App Store subscription review notes should state that safety and basic marketplace access are not paywalled.
- TestFlight should separately verify native purchases, RevenueCat restore/manage, AdMob test ads, push permissions, camera/photo permissions, proof upload, and PWA fallback messaging.

## What Should Not Be Copied

- Do not copy the video's app screens, exact layouts, graphics, product examples, or wording.
- Do not use threatening loss-aversion copy.
- Do not use fake countdowns, fake scarcity, or fake discounts.
- Do not blur safety or core marketplace value behind account/purchase walls.
- Do not copy any sponsor or third-party brand experience.

## How Ideas Map to MORT

- Smart defaults become safe role, locality, availability, and payment-preference guidance.
- Progress psychology becomes a real setup meter where account creation is counted as step one.
- Reciprocity becomes a useful free marketplace with visible safety tools before optional paywalls.
- Ownership becomes profile, skills, preferences, saved jobs, and portfolio setup.
- Loss framing becomes calm safety reminders, never pressure.
- Contrast/anchoring becomes honest plan context using RevenueCat price strings, never fake app prices.
