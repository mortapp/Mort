# AdMob Screen Eligibility Matrix

Ads are always blocked on auth, onboarding, age gate, Safety Ping, reports, messages, guardian approval, proof upload, verification, payment preference, admin, and paywall screens.

Potentially eligible later: teen job feed and non-sensitive discovery surfaces, only when `ADS_ENABLED=true`, native platform support exists, backend eligibility allows it, consent is ready, and the user lacks ad-free access.

Rewarded ads are optional and may never unlock safety, applying, proof, reports, blocking, or Guardian Mode. Web preview builds force ads off. Native AdMob has not been tested.
