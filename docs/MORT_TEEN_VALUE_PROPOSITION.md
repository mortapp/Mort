# MORT Teen Value Proposition

## Core Promise

Find appropriate nearby work, understand expectations, communicate safely after valid participation, complete the job, and build a truthful early work record that becomes useful beyond a single payment.

## Practical Value

- Age, schedule, travel, preference, and safety boundaries reduce irrelevant or unsuitable opportunities.
- Proposal guidance and clear application status make first-job behavior learnable.
- Participant-only messaging, report, block, Safety Ping, check-ins, and private proof protect coordination without promising zero risk.
- Reviews, references, skills, completion history, reflection, and a future private-by-default portfolio can support later applications and repeat clients.
- Availability, goals, reminders, and pause controls help work fit around school, health, family, and extracurricular commitments.
- Optional Guardian Mode can add selected support without making guardian linking a default access requirement.

## Rights And Boundaries

Basic browsing, applying, messaging for valid participants, proof submission, safety tools, privacy controls, account access, and deletion requests remain free. Exact teen location and private evidence must not become public. MORT does not guarantee income, employment, job legality, or safety.
