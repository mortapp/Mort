# MORT Retention Strategy

## Return For Value, Not Pressure

MORT should earn return visits when a relevant opportunity changes, a participant responds, a real commitment needs attention, a work history grows, or a user chooses to continue a practical goal. It should not manufacture urgency, punishment streaks, endless feeds, or shame.

## Healthy Loops

- Teen: saved criteria -> appropriate job -> application -> accepted work -> safe coordination -> completion -> review/reference -> stronger next opportunity.
- Adult/business: reusable brief -> qualified applicants -> clear decision -> scheduled work -> approved proof/closeout -> trusted worker -> repeat invitation.
- Guardian: voluntary link -> selected alert/check-in -> bounded context -> supportive action -> quiet digest or no further interruption.
- Community partner: approved page -> recurring opportunity -> roster/coordination -> outcome summary -> renewed local participation.

## Product Mechanics

- Saved searches and alerts with pause, frequency, deduplication, and quiet hours
- Availability and school/extracurricular boundaries
- Draft recovery and next-action summaries
- Skill Passport and Reference Builder with verified provenance
- Earning goals that use preference/record data only and never pretend MORT processed money
- Post-job reflection and optional practical learning
- Trusted-worker lists, repeat invitations, recurring jobs, and backup rosters
- Return-after-break guidance with no loss framing

## Guardrails

Never use expiring safety access, punitive streak loss, fake scarcity, disguised ads, default marketing pushes, humiliation leaderboards, or guardian surveillance as a retention device. Measure successful work and user-controlled pauses alongside notification opt-outs, reports, blocks, cancellations, and unhealthy-use feedback.
