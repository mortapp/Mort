# Guardian Mode vs Stripe Guardian

MORT Guardian Mode is optional safety support. It can expose only specifically authorized teen safety/job information and can be unlinked by the teen under current policy. It does not grant payout ownership, account control, message surveillance, or financial authority.

Any parent/guardian information Stripe requires for a minor connected account is a provider onboarding requirement governed by Stripe, the connected-account country, and applicable law. MORT records only a coarse synchronized requirement status. It does not infer that a MORT Guardian Mode connection satisfies Stripe requirements, and Stripe onboarding does not silently enroll anyone in Guardian Mode.
