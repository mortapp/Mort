# MORT Public Data Use Policy

## Allowed after source and legal review

- official government business-registration status
- official professional-license status when relevant to a job category
- official sanctions/disqualification data only after a written legal policy
- official school, nonprofit, and program directories for domain/organization review
- address-format validation that does not reveal resident information
- cryptographically verifiable official digital credentials

Every source must have a documented owner, jurisdiction, purpose, data fields, review method, freshness/expiry rule, appeal path, retention limit, and public-display boundary. Public data can create a private risk or review signal; it cannot automatically create a production identity badge.

## Privacy rules

MORT minimizes collected fields, does not publish residential information, does not expose school names by default, and does not expose email/phone values through trust profiles. Public-record snapshots must omit unnecessary owner/home-address fields. Reviewers receive only the least data needed for their role, with an access reason, case ID, actor, and timestamp.

Public data must never be used to make an automated criminal accusation or to describe a person as dangerous. Risk output is limited to neutral reason codes, a review recommendation, and a human-review flag.
