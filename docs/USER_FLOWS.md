# User Flows

## Teen

1. Sign up through Supabase Auth.
2. Complete DOB/role onboarding.
3. Browse local jobs.
4. Apply to a job.
5. Guardian approval is requested when needed.
6. Accepted-job messaging opens with scanner protection.
7. Teen can upload proof and use Safety Ping/report/block without payment.
8. Optional perks: Plus, ad-free, profile style, username token.

## Adult/Business

1. Sign up and complete adult onboarding.
2. Submit business verification.
3. Post jobs and review applications.
4. Accept/reject applicants and review proof.
5. Optional perks: Adult Pro and Job Boost.

## Guardian

1. Sign up and accept teen invite.
2. Review approvals and safety state.
3. Pause/resume teen activity.
4. Optional Guardian Plus adds richer digest/timeline later; basic Guardian Mode remains free.

## Admin

1. Admin role is server/admin-controlled.
2. Review reports, users, jobs, verification, support, and monetization audit.
3. Grant username credits where appropriate.
