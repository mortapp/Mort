# Monetization Review Notes

- All upgrades are optional convenience/style/business organization perks.
- Basic job browsing/applying, safety scanner, report, block, Safety Ping, proof basics, account access, and Guardian Mode basics stay free.
- App UI uses store-returned price strings; documentation targets are not app truth.

- Backend/webhook state controls entitlements and credits.
- Job payments remain preference-only and outside MORT; there is no escrow or payout processing.
- App Store Connect products, tax/banking agreements, native StoreKit testing, and review remain external work.
