# Stripe Minor Payouts

Payout eligibility is provider- and jurisdiction-dependent. MORT cannot promise a teen that payout setup or a payout will be available. Transfers remain disabled unless the connected account is in the correct environment, onboarding is complete, transfer capability is active, payouts are enabled, no restriction/dispute hold exists, and the completion path is eligible.

MORT never chooses or stores the external bank/debit destination. It may display provider-synchronized status, destination type, last four digits, estimated arrival, and failure code only to the account owner. Failed or restricted payouts require financial-operations review; support must not ask users to send bank or identity data in chat.
