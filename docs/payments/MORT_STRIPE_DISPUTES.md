# Stripe Disputes

Signed `charge.dispute.*` events create or update private dispute records and immediately hold transfer/refund paths that could worsen exposure. Only job participants see a minimal status projection; evidence, provider reason details, deadlines, and financial actions are restricted to time-bounded financial roles.

MORT does not auto-decide fault, debit a teen, publish allegations, or ask for evidence in ordinary chat. Operations preserve relevant job/payment evidence under the retention policy, respond in Stripe Dashboard where required, update the case record, and communicate neutral status. Won/lost/withdrawn-funds states must be reconciled before releasing any hold.
