# MORT Play Console App Access - Final

Open MORT and tap Sign in. Enter play-review@mortapp.test, then tap Continue as Play Reviewer. No password, email link, OTP, or 2-step verification is required. This opens an isolated demo environment with synthetic data. Use Review Role to access Teen, Adult, Guardian, Support, and Admin demo views. Live payments, payouts, refunds, ID checks, ads, IAP, Google sign-in, and the public marketplace are disabled. No real user data or destructive actions are available.

The reviewer identifier is not a Supabase Auth account and has no password, token, role, entitlement, or production tenant. Reviewer state is held only in memory and expires on exit or process restart.
