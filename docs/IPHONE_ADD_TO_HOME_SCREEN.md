# Add MORT to iPhone Home Screen

1. Deploy the web artifact to a real HTTPS host such as Netlify.
2. Open the generated URL in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Keep the name `MORT` and tap Add.
6. Open MORT from the Home Screen.
7. Test sign-up, confirmation, sign-in, refresh/session restore, onboarding, jobs, applications, messages, report/block, Safety Ping, support, and settings.

The web preview cannot validate StoreKit purchases, native AdMob, APNs push permissions, or full iOS camera/photo behavior.
