# Founder and Manager Permissions

Use individual Google accounts with two-step verification. The account owner retains payments-profile ownership, app transfer, Play App Signing, user administration, and production release authority.

| Role | Grant | Do not grant |
| --- | --- | --- |
| Release manager | View app, manage testing tracks, upload releases, view pre-launch reports | Account ownership, payments profile, user administration |
| Store manager | Store presence and listing management | Releases, financial data, signing |
| Policy/safety reviewer | App content, policy status, ratings, data-safety drafting | Production publishing, finance |
| Financial reviewer | Orders/subscriptions and financial reports when required | User management, signing, source secrets |
| QA lead | Testing tracks, tester lists, vitals/pre-launch read access | Production publishing, payments profile |

Revoke access when duties end, review permissions quarterly, and record every production promotion. No role in Play Console confers MORT database admin access.
