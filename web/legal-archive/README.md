# MORT public legal and safety site

This directory contains the classic black and white reading layout for `legal.mortapp.org`. Legal wording and account deletion behavior are generated by `scripts/build-public-legal-site.mjs` into `web/public`. The main MORT website is the separate Flutter web build configured at the repository root.

## Build and verify

Run `pnpm install --frozen-lockfile` at the repository root to install the pinned Supabase browser bundle. Set the six `MORT_PUBLIC_*` publisher, contact, website, and effective-date variables required by the generator. Supply only the public Supabase anon key through `EXPO_PUBLIC_SUPABASE_ANON_KEY`; never supply a service-role key. Then run `npm run build` here. Check `web/public/release-status.json` and all generated routes before any deployment.

Run `npm test` and `npm run check` here. The tests cover the semantic layout, document routes, and the presence of the account-deletion controls. Run `node scripts/qa-account-deletion-web.mjs` from the repository root to check the ownership-verification contract. Browser review should use the available browser testing workflow against a local server serving `web/public`; do not submit real account-deletion forms during layout testing.

The site renders as normal HTML and CSS. It has no decorative canvas or animation bundle. On the deletion route, the public Supabase anon client requests a private sign-in link, and the server RPC remains responsible for authorizing deletion. Legal approval and public deployment are separate gates.
