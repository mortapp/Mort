# Stripe Monitoring

Alert on webhook signature failure spikes, repeated processing failures, stale received events, amount/currency/environment mismatch, duplicate provider IDs, payment funded without contract alignment, eligible completion without transfer, transfer failure/reversal, payout failure, new dispute, refund failure, and reconciliation mismatch.

Dashboards expose counts and safe codes, not card, bank, identity, raw payload, message, or teen evidence data. Financial-role access is individual, expiring, audited, and reviewed. Sandbox and live alerts are visibly separated. Live operations need an on-call owner, escalation contacts, daily reconciliation, provider status checks, and documented incident severity/response targets.
