# MORT Final Design System

- Background: `#050607`; elevated background: `#0D1012`.
- Cards: `#12161A`; alternate surface: `#191F24`; border: `#273038`.
- Brand: neon green `#7CFF6B`; safety blue `#4DB8FF`; premium purple `#9E7CFF`.
- Status: warning `#FFB34D`; danger `#FF5A6A`.
- Text: primary `#F3F7F2`; soft `#C7D0CA`; muted `#9AA6A0`.
- Spacing uses the centralized 4/8/12/16/20/28/36 scale.
- Buttons have a minimum 52 pixel height, visible disabled/loading states, and icon plus text labels.
- Screens use safe areas, a 760 pixel content cap, and mobile-first scrolling.
- Motion is limited to progress/loading feedback and respects reduced-motion in the PWA loader.
- The MORT mark uses the existing dark, neon, and safety-blue tokens and replaces Flutter placeholder branding.
